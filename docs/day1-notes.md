## Git Basics

- Git tracks file changes and maintains version history.
- GitHub hosts Git repositories online.
- A repository contains project files and their Git history.
- A branch allows changes to be developed separately.
- A commit records a snapshot of changes.
- Push uploads local commits to a remote repository.
- Pull retrieves remote changes.

## CI/CD Basics

- CI stands for Continuous Integration.
- CD stands for Continuous Delivery or Continuous Deployment.
- GitHub Actions automates workflows.
- Workflows are defined using YAML.
- Events such as push can trigger workflows.
- Jobs run on runners.
- Steps execute sequentially within jobs.
- GitHub-hosted runners can run on Ubuntu.
